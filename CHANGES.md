# Changes

## 2026-11-19 v0.14.0

### Improvements
- Removed Vim modeline comments from `Gemfile` and `Rakefile`.
- Updated the header comment in `lib/all_images/version.rb` to clarify
  that the file is auto-generated by `GemHadar` and should not be
  edited manually.

### Build & CI
- Raised the minimum required version of the `gem_hadar` development
  dependency from **2.18.0** to **2.24.1** to support `json` **3.x**
  migration.

## 2026-10-08 v0.13.0

### Fixes
- Fixed `#env` to stop mutating `@config`, build `env_hash` immutably, set
  `ALL_IMAGES` to `?1`, and use host `TERM` only as a fallback.

### Improvements
- Added an `env:` section to `.all_images.yml` pinning `TERM=xterm`,
  `COLUMNS=80`, and `LINES=25`.

### Build & CI
- Added steps to `.all_images.yml` to remove `Gemfile.lock` during CI.
- Updated `all_images.gemspec` to set `rubygems_version` to **4.0.22** and
  require `gem_hadar` >= **2.18.0**.

### Testing
- Added specs in `spec/app_spec.rb` to assert `COLUMNS`, `LINES`, and `TERM`
  inside the container, guarded by `skip 'not in all images'`.

## 2026-01-17 v0.12.0

### Features
- Added `before` and `after` configuration hooks in `.all_images.yml`
  to run pre- and post-execution scripts.
- Introduced the `RESULT` environment variable to enable decision
  making in `after` hooks.
- Enhanced the `sh` method with a `crash` keyword argument, allowing
  non-fatal command execution when set to `false`.
- Updated the `run_image` method to execute configured hooks and track
  test results.

### Improvements
- Removed the `bundle update --all` command from the project's
  `script` definition in `.all_images.yml`.
- Updated `rubygems_version` from **4.0.2** to **4.0.3**.
- Updated the `gem_hadar` development dependency to require
  **>= 2.17.0**.

### Testing
- Added a skipped test case verifying that assertions can fail.

## 2026-01-02 v0.11.2

### Improvements
- Updated rake execution to use `bundle exec` for consistent dependency
  management.

## 2026-01-02 v0.11.1

### Fixes
- Handle `nil` configuration gracefully in `images` to improve robustness
- Escape ANSI sequences in config script

## 2026-01-02 v0.11.0

### Features
- Added support for `ruby:4.0-alpine` to `lib/all_images/config.rb` for
  consistent image definition configuration.
- Included `CHANGES.md` in the package by updating the `changelog`
  configuration in `all_images.gemspec`.

### Improvements
- Updated the CI configuration to use `ruby:4.0-alpine` instead of
  `ruby:4.0-rc-alpine` for testing against the stable Ruby **4.0** release.

### Build & CI
- Updated the `gem_hadar` dependency to version **2.16.3** or higher.

## 2025-12-21 v0.10.0

### Improvements

  instead of `bundle update` for consistent dependency management.

### Build & CI
- Updated the `gem_hadar` development dependency from `~> 2.7` to
  `~> 2.12`.
- Added `ruby:4.0-rc-alpine` to the CI test matrix.

### Documentation
- Expanded `README.md` with detailed architecture, usage, and configuration
  documentation.

## 2025-10-09 v0.9.0

### Features
- Added **ruby:3.1-alpine** to the CI image matrix.

### Fixes
- Added **openssl-dev** to the Dockerfile build environment.

### Improvements
- Added `yaml`, `fileutils`, and `shellwords` as explicit runtime dependencies.
- Updated Dockerfile to run `gem update --system` before installing gems.
- Replaced `bundle` with `bundle update` and `bundle install --jobs` in
  the default script for parallel installation.
- Enabled `fail_fast: true` in the default CI configuration.
- Updated the default configuration example to reflect the new
  Dockerfile and script settings.

### Build & CI
- Bumped **gem_hadar** dependency from **2.4** to **2.7**.

## 2025-09-11 v0.8.0

### Improvements
- Improved image matching logic by replacing the direct
  `images.map(&:first).grep(...)` call with a separate `image_names`
  variable for cleaner search behavior.

### Build & CI
- Relaxed the `tins` runtime dependency constraint from `~> 1.42` to
  `~> 1` in `Rakefile` and `all_images.gemspec`.
- Updated the `gem_hadar` development dependency from `~> 2.2` to `~> 2.4`
  in `Rakefile` and `all_images.gemspec`.

## 2025-09-03 v0.7.0

### Breaking
- Removed support for Ruby **3.0** and **3.1**.

### Features
- Integrated `SearchUI` to allow interactive, fuzzy-search selection
  of Docker images when no image is specified for `run` or `debug`
  commands.
- Added support for Ruby **3.4** using the `ruby:3.4-alpine` image
  configuration.
- Updated example Dockerfile configuration to include `yaml-dev` and
  remove unnecessary `gem update` and `bundler` installation steps.

### Improvements
- Simplified `SimpleCov` setup by replacing manual configuration with
  `GemHadar::SimpleCov.start`.
- Added `info_puts` method to provide colored console logging for image
  building and container execution status.
- Reworked `load_config` to consistently check for configuration file
  existence regardless of provided arguments.
- Added comprehensive YARD documentation to `AllImages`, `App`, and
  `Config` modules.
- Removed obsolete `binary` option from the `discover` block in the
  utils configuration.

### Build & CI
- Updated `tins` dependency from **1.0** to **1.42**.
- Added `search_ui` dependency.
- Updated `term-ansicolor` dependency to **1.11** with an explicit
  version constraint.
- Updated `gem_hadar` development dependency to **2.2**.
- Added `.yardoc` to the list of ignored files in `.gitignore` and
  packaging ignore lists.
